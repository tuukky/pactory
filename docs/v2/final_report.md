# 최종 보고서 — 모터 공장 v2 공정설계

> 가상 공장 / 합성 가정 / 실제 공장 성능 검증 아님

## 요약

합성 입력 기반 21개 설비·2개 서브라인·BOM 동기화 모터 공장을 이산사건 시뮬레이션으로 공정설계했다. 설비 고장·작업자 숙련·AGV 물류를 모델링하고, 이 계층들을 무력화하면 검증된 단일 라인 모델(v1 `line_sim`)과 주문별 출하시각까지 일치함을 확인했다(V11). 초기 설계의 손실을 원인별로 분해해 **2회 설계 개정**(1단계 1회 + 2단계 증산 1회)으로 다음 결과를 얻었다.

- 1단계(수요 18대/h): 수요 충족률 0.992, 납기 충족률 0.994, 리드타임 2.0h를 확인 시드 30회에서 달성했다(`final_confirm_20261026T231642_2101408a`).
- 2단계(수요 20.7대/h): 수요 충족률 0.993, 납기 충족률 0.993, 리드타임 2.0h를 독립 확인 시드 30회에서 달성했다(`p2_final_confirm2_20261027T000159_344e6f56`).
- 최종 Rev.C는 수요 23.8대/h, 고장 2배, 품종 C 증가 조건에서도 목표를 유지했다(CI 경계 기준 포함). 그 이상의 조건은 시험하지 않았다.

최종 구성은 Rev.A 대비 운영 규칙 2개만 바꿨다: 하우징 발주점 s 300 → 800, 키트 슬롯 K 30 → 45. 설비·작업자·AGV는 추가하지 않았다.

## 1. 설계 질문과 목표

- 질문: 주간 수요와 납기를 달성하는 공정 구성은 무엇이고, 초기 설계(Rev.A)에서 어떤 개정을 거쳐 도달했는가(PLAN_v2 §1). 2단계: 수요 20.7대/h를 감당하는 구성은 무엇인가(§17).
- 목표(D5~D7): 수요 충족률 ≥ 0.98, 납기 충족률 ≥ 0.95, 도착 코호트 리드타임 하한 ≤ 16h.
- 선정 기준: 목표 만족 + 변경 용이성 순위 최소(규칙·재배분 0 < 버퍼 증설 1 < 숙련 2 < AGV 3 < 작업자 4 < 설비 5). 비용 계산 없음.
- 실행: 1 run = 워밍업 80h + 관측 160h. 탐색 시드 100~119(20회), 확인 시드 1000~1029 / 2000~2029(30회).

## 2. 보정과 사전 계산

- 보정(시드 1~9, `calibration_20261026T230428_cbf19de2`): 준비 비율이 R1 49%, S3 45%로 범위(5~15%) 밖이라 준비시간에 공통 배율 0.125를 적용했다(R1 300→37.5s, S3 240→30s → 10.8%, 9.3%). DOWN 비율 7.3%, EOL 최초 통과율 95.2%는 범위 안이라 그대로 두었다. 워밍업은 MSER-5 d* = 0h로 80h를 유지했다(docs/v2/calibration.md).
- 정적 계산(docs/v2/static_capacity.md): 공정 이용률 1위는 S5 오븐(실효 15.4대/h, 이용률 1.17)이었다. 하우징 (s, Q) = (300, 600)의 공급 상한은 12.3대/h로 별도 계산됐지만 공정 이용률 표에는 드러나지 않는다.

## 5. 가설 판정 (기각 보존)

| 가설 | 판정 | 요지 |
|---|---|---|
| H1 1차 병목 = 정적 부하 최대 공정 | **기각** | 정적 계산은 오븐을 꼽았지만 처리량을 정한 것은 하우징 재고 정책과 투입 통제(K)였다. 공정 이용률 표가 놓치는 제약을 시뮬레이션이 드러냈다. |
| H2 병목 해소 시 다른 자원 유형으로 이동 | **지지** | 자재 정책 → 투입 통제·오븐 → AGV(이용률 65→82%, 오븐 운반 막힘 2.2→8.0%)·포장 작업자(대기 7.7→11.5%). 아직 지배적 제약은 아니며 다음 제약 후보다. |
| H3 같은 총 버퍼라도 배분이 중요, 병목 앞이 우수 | **부분 기각** | 비병목 집중이 +15%에서 리드타임을 악화시킨 경우만 확인. 병목 앞 집중의 이점은 두 단계 모두 확인 못함. CONWIP K가 WIP를 묶어 배분 효과가 작다. |
| H4 FAMILY가 준비를 줄이고 처리량↑, 품종 C 납기↓ | **부분 지지 / 일부 기각** | 준비 감소는 지지(R1 −2.5%p, S3 −0.8%p @ +15%). 처리량 증가와 품종 C 저하는 확인 못함. 보정 후 준비가 짧아 효과 자체가 작다. |

## 7. 해석 시 주의 (docs/v2/limitations.md)

- 모든 수치는 합성 가정 기반 가상 공장 결과다.
- 정비 인력 경합·AGV 혼잡을 모델링하지 않아 고장·운반 손실을 과소평가할 수 있다. 특히 Rev.C의 AGV 이용률 82%는 혼잡을 넣으면 제약이 될 수 있다.
- 2단계 질문은 1단계 결과를 본 뒤 정했고 탐색 시드를 재사용했다. 독립 확인 시드로 완화했다.
- 납기 충족률은 공통 난수로 고정된 폐기율 때문에 약 0.993에서 포화해 개정 간 변별력이 거의 없다.
- 개정은 두 번 모두 운영 규칙 변경이었다. 설비·인원 추가가 필요한 설계 공간(23.8대/h 초과)은 탐색하지 않았다.
