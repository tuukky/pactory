# 설계 개정 이력 (PLAN_v2 §9.2)

모든 수치는 합성 가정 기반 가상 공장의 시뮬레이션 결과다. 실제 공장 성능을 검증한 값이 아니다.

## 실험 조건

| 항목 | 내용 |
|---|---|
| 실행 길이 | 1회 = 워밍업 80h + 관측 160h |
| 시드 | 탐색 100~119 (20회), 확인 1000~1029 (30회) |
| 짝 비교 | 같은 시드끼리 d_i = 후보 − 기준, 평균과 95% t 신뢰구간 |
| 목표 (D5~D7) | 수요 충족률 ≥ 0.98, 납기 충족률 ≥ 0.95, 도착 코호트 평균 리드타임 하한 ≤ 57,600s(16h) |
| 실험 행렬 | `configs/v2/experiments.yaml` |
| 결과 위치 | `results/v2/<experiment_id>/` (runs_index, summary, stations_summary, paired, targets, selection) |

**규칙** (실행 전에 고정했고, 결과를 본 뒤 바꾸지 않았다)
- **primary_metric**: 직전 진단에서 목표 대비 상대 미달이 가장 큰 목표 지표.
- **채택**
  1. primary의 CI가 개선 방향으로 0을 포함하지 않고, 다른 목표 지표의 CI가 전부 악화 쪽에 있지 않은 후보만 적격이다.
  2. 적격 후보 중 변경 용이성 순위가 가장 낮은 후보를 고른다. 동률이면 primary 개선 폭이 큰 후보를 고른다.
  3. 변경 용이성 순위: 규칙·재배분(0) < 버퍼 증설(1) < 숙련(2) < AGV(3) < 작업자(4) < 설비(5). 이 순서는 설계자가 정한 가정이며 비용이 아니다.
- **종료**: 탐색 20시드 평균으로 목표 3개를 모두 만족하거나, 개정이 6회에 이르면 멈춘다.

**기각 이유**
- **H2**: Q를 늘려도 리드타임 중 수요가 s보다 큰 구조는 그대로다. 결품이 남는다(122,224s).

- **H4**: S4의 하류 막힘을 줄였지만 공장 처리량은 투입이 결정하므로 효과가 미미했다.

**동결**
- 명령: `python -m factory_sim.experiments freeze --study rev1 --candidate H1 --as B`
- 생성 파일: `configs/v2/rev_B.yaml`

**종료 판정**: Rev.B가 탐색 20시드 평균으로 목표 3개를 모두 만족한다. §9.2-6에 따라 개정을 멈췄다. 개정 횟수는 1회이고, **최종 Rev는 B**다.
