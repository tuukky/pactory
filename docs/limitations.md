# 모델 한계

이 결과는 합성 가정 기반 가상 라인의 비교 실험이며 실제 공장 성능 검증이 아니다.

## 데이터

- 작업시간·불량률·회복확률·설비 수·버퍼·주문량·준비시간은 모두 임의로 정한 실험 값이다. 실측값·산업 평균이 아니다.
- 처리시간 로그정규분포(CV 0.10)는 음수 방지를 위한 모델 가정이며 현장 분포 추정 결과가 아니다.
- 가상의 소형 모터 제품군 P1·P2·P3이며 실제 제조 공법을 재현하지 않는다.

## 공정 모델

- **독립 재검사 장비**: 재작업 셀이 자체 재검사 장비를 가진다고 가정한다. 불합격품을 동일 TEST로 되돌리지 않으므로 실제 공유 재검사 라인보다 TEST 부하를 작게 평가할 수 있다.
- **이동시간 0**: 버퍼와 공정 사이는 논리적 흐름이다. 운반 인력·컨베이어·거리 기반 운반능력을 구현하지 않았으므로 물리적 물류 최적화 성과를 주장하지 않는다.
- BOM 동기화(부품 합류)는 범위 밖이다. 제품 1개 = Job 1개.
- 작업자 공유·휴게·교대 교체·협동 작업을 모델링하지 않는다. 8시간은 순가동시간이다.
- 폐기품의 대체 주문은 만들지 않는다. 양품 480개 달성을 보장하지 않는다.
- 공정 연결도는 논리도이며 실제 치수·통로·안전거리를 검증한 레이아웃이 아니다.

## 미구현 기능

- **고장(DOWN)**: 상태 enum과 지표의 `down` 필드(항상 0)만 있다. 고장·수리 동작은 구현하지 않았고 UI에 노출하지 않는다. (TODO: PLAN §15 선택 기능 — 재개·시간 보존 테스트와 함께 추가할 때만 최종 버전에 포함)
- 3D 재생(PLAN §14), 손익분기 계산(PLAN §12)은 구현하지 않았다.

## 지표·통계

- 무작업(STARVED)에는 주문 종료 후 무작업도 포함된다. 이 지표만으로 공급 부족이라고 단정하지 않는다.
- 교대 시점 완료품 기준 체류시간에는 선택 편향이 있다. 미완료 수·나이를 함께 본다.
- 20회·30회 반복은 일정상 예산이며 충분한 표본 수를 보장하지 않는다.
- 탐색 후보 선택 편향은 독립 확인으로 완화하지만 완전히 제거되지 않는다.
- high_load_mix 조건은 주문 집합이 달라 기본 조건과 같은 시드로 짝 비교할 수 없다.
- 설비 가격·운영비를 모르므로 투자회수기간을 계산하지 않는다. 물리적 투입 차이(설비 +1대, 슬롯 +8 등)만 보고한다.
